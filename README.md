# ClearTranslate

ClearTranslate is a Flutter-based cross-platform Chinese-English translation tool focused on a clean, fast, privacy-first experience.

## Current Stage

Phase 0: product prototype and technical validation.

## Planned Platforms

- Windows
- macOS
- Android
- iOS

## Getting Started

Install Flutter, then run:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

If native platform folders are not present yet, generate them with:

```powershell
flutter create .
```
